# QuickMO
Retarget Quickmagic, UE5.6+, Mixamo, and more to Rigify &amp; Rig2U5

* No need to connect to internet services
* Autonomous / local - You mocap, you retarget.
* Updated and MANTAINED to work with latest Blender 5.2+
* Quickmagic Native Rig retarget
* Quickmagic Unreal Engine 5.6+ Rig retarget
* Quickmagic Mixamo Rig retarget
* Unreal Engine 5.8 native FBX Mocap retarget
* Mixamo Native fbx Mocap retarget
* MMD/VMD Mocap retarget
* SuperTK Mocap retarget
* Drag and drop rigs populate the addon
* Autoscaling + Autoretargeting: No more fighting A/T/ variant poses.
* Presets ready to retarget from Drop down.
* Auto Warning if a Mocap profile doesn't match your fbx file.
